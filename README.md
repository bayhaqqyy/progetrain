# KodeKita — Website Edukasi Web Development

KodeKita adalah website edukasi satu halaman untuk pemula yang ingin mempelajari dasar HTML, CSS, dan JavaScript. Proyek dibuat dengan HTML5, custom CSS responsif, dan JavaScript vanilla tanpa framework wajib.

## Cara menjalankan

1. Buka folder `kodekita`.
2. Klik dua kali `index.html`, atau buka dengan browser.
3. Jika memakai VS Code, boleh dijalankan menggunakan ekstensi Live Server.

## Komponen tugas yang tersedia

- Heading dan paragraph
- Text formatting (`strong`, `small`, `blockquote`, `code`)
- Link internal dan eksternal
- Image dengan alt text
- Ordered list dan unordered list
- Table beserta caption, thead, tbody
- Form: text, email, select, radio, checkbox, textarea
- Video HTML5
- Audio HTML5
- Custom CSS, responsive layout, dark mode
- JavaScript: filter materi, detail materi, localStorage progress, dark/light mode, mobile navigation, quiz + skor otomatis, validasi form, toast notification, dan scroll reveal

## Struktur

```text
kodekita/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── learning-illustration.svg
```

Catatan: contoh video dan audio menggunakan sumber media publik eksternal sehingga membutuhkan koneksi internet untuk diputar. Bagian utama website tetap dapat dibuka secara lokal.
